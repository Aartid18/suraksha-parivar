# Security Policy - Suraksha Parivar

## Reporting Vulnerabilities
We take security and privacy seriously. If you discover a vulnerability in Suraksha Parivar, please email `security@surakshaparivar.org` (or open a private security advisory).

### Key Commitments
- **No Operational Phishing Material**: All sample messages and dataset entries are strictly synthetic.
- **PII Redaction**: Raw user text is redacted before any processing.
- **No Automatic External Actions**: Suraksha Parivar provides guidance and evidence packs; it never automatically files official reports or contacts law enforcement on behalf of users.
