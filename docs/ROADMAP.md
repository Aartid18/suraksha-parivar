# Project Roadmap - Suraksha Parivar

## Phase 1: MVP Core (Completed)
- [x] Hybrid detection engine (Rules + LLM + Vector KB)
- [x] Tri-lingual support (English, Hindi, Marathi)
- [x] Family Circle & Granular Consent Guardian Alerts
- [x] First 30 Minutes Incident Flow & Evidence Pack PDF
- [x] Offline Evaluation Harness (87.78% F1 Score)

## Phase 2: Stretch Features (Next Up)
- [ ] **Voice Note Input**: Indian-language ASR (AI4Bharat / Bhashini integration) to transcribe voice calls directly into Quick Check.
- [ ] **Web Share Target API**: Share suspicious texts directly from WhatsApp / SMS into Suraksha PWA in 1 tap.
- [ ] **Spot the Scam Quiz**: Gamified 10-question scam awareness game with shareable scorecards.
- [ ] **On-Device Small LLM**: Run lightweight quantized classification on-device via WebAssembly/WebGPU.
