# उपयोगकर्ता मार्गदर्शिका - सुरक्षा परिवार (हिंदी)

> **नोट**: यह मार्गदर्शिका भारतीय परिवारों के लिए सरल भाषा में तैयार की गई है।

## संदेश की जांच कैसे करें
1. **मैसेज डालें**: व्हाट्सएप संदेश, एसएमएस या फोटो यहां पेस्ट करें।
2. **परिणाम देखें**:
   - 🟢 **हरा (सुरक्षित)**: संदेश सामान्य है।
   - 🟡 **पीला (संदिग्ध)**: सावधान रहें और आधिकारिक ऐप से जांचें।
   - 🔴 **लाल (संभावित फ्रॉड)**: ओटीपी या यूपीआई पिन न डालें और पैसे न भेजें!
3. **आवाज में सुनें**: 'बोलकर सुनाएं' बटन दबाकर हिंदी में सुनें।
4. **परिवार को सूचित करें**: 'परिवार से पूछें' बटन दबाकर अभिभावक को अलर्ट भेजें।

## यदि पैसे या ओटीपी दे दिए हैं तो क्या करें
1. तुरंत **"मैंने पैसे / ओटीपी दे दिए हैं"** टैब पर जाएं।
2. 6-चरणीय गाइडेड सूची का पालन करें।
3. **1930** (राष्ट्रीय साइबर अपराध हेल्पलाइन) पर कॉल करें।
4. **"पीडीएफ (PDF) साक्ष्य डाउनलोड करें"** बटन दबाएं।
