# Design System & Accessibility - Suraksha Parivar

## Design Philosophy
- **Calm Reassurance**: Scammers exploit panic and isolation. The design system uses calm, warm, reassuring tones (Deep Teal `#0F766E`, Warm Saffron `#F59E0B`, Soft Off-White `#F8FAFC`).
- **Devanagari First**: Built with `Noto Sans Devanagari` and `Inter` with custom line-height scaling for readability by elderly users.

## Color Tokens
- **Primary / Brand**: Deep Teal (`#0F766E`, Tailwind `teal-700`)
- **Accent / Caution**: Warm Saffron (`#F59E0B`, Tailwind `amber-500`)
- **Safe / Genuine**: Emerald Green (`#10B981`, Tailwind `emerald-500`)
- **Likely Scam**: Muted Red (`#DC2626`, Tailwind `rose-600`)

## Accessibility Features
- WCAG 2.2 AA Contrast Compliance across light and dark modes.
- `A-` / `A+` font scaling toggle (`0.9x`, `1.0x`, `1.15x`, `1.3x`).
- Web Speech API TTS read-aloud support for Hindi, Marathi, and English.
- Screen-reader aria-labels and keyboard navigation.
