# वापरकर्ता मार्गदर्शिका - सुरक्षा कुटुंब (मराठी)

> **टीप**: ही मार्गदर्शिका मराठी कुटुंबांसाठी सोप्या भाषेत तयार केली आहे.

## मेसेज कसा तपासावा
1. **मेसेज टाका**: व्हॉट्सॲप मेसेज, एसएमएस किंवा फोटो इथे टाका.
2. **निकाल पहा**:
   - 🟢 **हिरवा (सुरक्षित)**: मेसेज सामान्य वाटतो.
   - 🟡 **पिवळा (संशयास्पद)**: सावध राहा आणि अधिकृत ॲपवरून तपासा.
   - 🔴 **लाल (फसवणूक)**: ओटीपी किंवा युपीआय पिन टाकू नका आणि पैसे पाठवू नका!
3. **आवाजात ऐका**: 'ऐकवा' बटण दाबून मराठीत ऐका.
4. **कुटुंबाला सावध करा**: 'कुटुंबाला विचारा' बटण दाबून पालकाला अलर्ट पाठवा.

## पैसे किंवा ओटीपी दिले असल्यास काय करावे
1. **"मी आधीच पैसे / ओटीपी दिले आहेत"** बटणावर क्लिक करा.
2. ६-टप्प्यांच्या मार्गदर्शकाचे पालन करा.
3. **१९३०** (राष्ट्रीय सायबर गुन्हा हेल्पलाइन) वर कॉल करा.
4. **"पीडीएफ (PDF) पुरावा डाउनलोड करा"** बटण दाबा.
