# Changelog - Suraksha Parivar

All notable changes to **Suraksha Parivar** will be documented in this file.
The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-09-23
### Added
- **Hybrid Scam Detection Engine**: Rule-based detection + LLM structured classification + vector knowledge base retrieval.
- **Tri-lingual UI & Content**: Full English, Hindi, and Marathi support for all screens, red flags, advice, and read-aloud TTS.
- **Family Circle & Guardian Alerts**: Consent-driven alerts with 1-tap WhatsApp and phone call actions.
- **First 30 Minutes Incident Flow**: Interactive guided checklist with active timer and downloadable Evidence Pack PDF.
- **Evaluation Harness**: Multilingual 400+ item dataset with precision, recall, F1, latency, and cost metrics reporting.
- **PWA & Offline Scam Library**: Service worker support for offline access to emergency guides and scam pattern library.
